# ADR-003: Recharts como biblioteca de gráficos do dashboard

## Status

Aceito

## Data

2026-07-01

## Contexto

O dashboard admin não tem nenhuma biblioteca de gráficos instalada. A feature F8 exige gráfico de vendas por período (linha ou barras) e lista visual de top produtos. É necessário escolher uma biblioteca compatível com Next.js App Router (Client Components) e com a identidade visual já definida (Tailwind CSS, paleta TechnicFix).

## Decisão

Instalar e usar Recharts. Os componentes de gráfico são Client Components (`'use client'`); os dados são buscados no Server Component do dashboard e passados via props.

## Alternativas Consideradas

### Alternativa 1: Tremor

- **Descrição**: Biblioteca de componentes de dashboard que inclui métricas, gráficos e tabelas prontos.
- **Prós**: Menos configuração; componentes prontos com boa aparência padrão.
- **Contras**: Opinativo no estilo; dificulta customização da paleta da marca; adiciona abstração sobre Recharts (que ele usa internamente).
- **Por que rejeitada**: Menor controle sobre aparência; dependência mais pesada para o que é necessário.

### Alternativa 2: Chart.js via react-chartjs-2

- **Descrição**: Biblioteca de gráficos canvas-based com wrapper React.
- **Prós**: Ampla base de usuários; muitos tipos de gráfico.
- **Contras**: API mais verbosa; canvas-based (pior para SSR/hidratação); menos idiomático no ecossistema React moderno.
- **Por que rejeitada**: Mais verboso e menos integrado com o padrão de componentes React atual.

## Consequências

### Positivas

- Padrão de facto no ecossistema shadcn/Next.js — documentação abundante.
- SVG-based — sem problemas de hidratação.
- Aceita cores via props (fácil integrar com paleta Tailwind CSS).
- Bundle leve (~70KB gzip).

### Negativas

- Requer um Client Component wrapper para cada gráfico (não funciona diretamente em Server Components).
- Necessita de instalação (`npm install recharts`).

### Riscos

- Versão do Recharts deve ser compatível com React 19 — verificar antes de instalar.
