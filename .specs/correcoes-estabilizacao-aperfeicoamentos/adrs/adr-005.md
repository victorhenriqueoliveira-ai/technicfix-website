# ADR-005: /categorias/[slug] como URL canônica de categoria

## Status

Aceito

## Data

2026-07-17

## Contexto

Após a criação das landing pages de categoria em `/categorias/[slug]`, dois URLs existirão para o mesmo conteúdo: `/categorias/parafusos` (nova landing page) e `/produtos?categoria=parafusos` (URL histórica com filtro). Para evitar conteúdo duplicado que prejudique SEO, uma das URLs deve ser declarada canônica.

## Decisão

`/categorias/[slug]` passa a ser a URL canônica para páginas de categoria. A página `/produtos?categoria=[slug]` adiciona `<link rel="canonical" href="/categorias/[slug]">` via `generateMetadata`. A landing page `/categorias/[slug]` não declara canonical redundante (é a própria canônica).

## Alternativas Consideradas

### Alternativa B: /produtos?categoria=[slug] permanece canônica

- **Descrição**: A landing page `/categorias/[slug]` declara canonical apontando para `/produtos?categoria=[slug]`.
- **Prós**: Preserva todo o valor de SEO acumulado historicamente na URL de produtos com filtro.
- **Contras**: A URL com query string (`?categoria=`) é menos autoritativa para SEO do que uma URL limpa (`/categorias/parafusos`). Investe em infraestrutura de landing page sem colher o benefício SEO de longo prazo.
- **Por que rejeitada**: O objetivo de F9 é criar URLs de categoria indexáveis e compartilháveis. Manter a URL com query string como canônica contradiz esse objetivo.

## Consequências

### Positivas

- `/categorias/[slug]` acumula autoridade de SEO ao longo do tempo por ser URL limpa e indexável.
- Links externos para `/categorias/parafusos` serão indexados diretamente.
- URLs são compartilháveis e legíveis por humanos.

### Negativas

- Qualquer autoridade de SEO existente em `/produtos?categoria=[slug]` não é transferida automaticamente — o `rel=canonical` instrui o Google a preferir a nova URL, mas a transferência de ranking leva semanas.
- A página `/produtos` continua funcionando normalmente com o filtro ativo; apenas a sinalização SEO muda.

### Riscos

- Se `/produtos?categoria=[slug]` tiver backlinks externos significativos, a transição pode causar queda temporária de ranking. Mitigação: monitorar Google Search Console após o deploy de F9.

## Notas de Implementação

```typescript
// app/(public)/produtos/page.tsx — generateMetadata com canonical quando categoria está ativa
export async function generateMetadata({ searchParams }) {
  const { categoria } = await searchParams
  if (categoria) {
    return {
      alternates: {
        canonical: `/categorias/${categoria}`,
      },
    }
  }
  return { title: 'Produtos — Technicfix' }
}
```
