# ADR-004: Pill Badges da Hero Configurados via SiteConfig

## Status

Aceito

## Data

2026-07-15

## Contexto

A hero section precisa de pill badges visuais (ex.: "Frete Grátis", "Qualidade Premium") para comunicar propostas de valor ao visitante. A questão é se esses textos devem ser fixos no componente ou editáveis pelo admin sem necessidade de deploy.

## Decisão

Adicionar dois campos opcionais ao modelo `SiteConfig`: `heroBadge1 String?` e `heroBadge2 String?`. O componente `Hero` os recebe como props e renderiza cada pill somente quando o campo não for nulo/vazio. Isso permite que o admin do painel edite os badges sem deploy.

## Alternativas Consideradas

### Alternativa 1: Hardcoded no componente

- **Descrição**: Textos dos pills fixos em `Hero.tsx` como constantes.
- **Prós**: Zero migração de BD, implementação imediata.
- **Contras**: Qualquer alteração no texto requer commit + deploy; não editável pelo admin.
- **Por que rejeitada**: Usuário expressamente escolheu a opção configurável via BD.

## Consequências

### Positivas

- Admin pode ajustar a mensagem dos badges em campanhas sem deploy (ex.: "Frete Grátis em Compras Acima de R$ 200").
- Pills não aparecem quando os campos estiverem nulos — comportamento seguro por padrão.

### Negativas

- Requer migração de BD para adicionar dois campos a `SiteConfig`.
- A interface admin precisará expor esses dois novos campos para edição (fora do escopo deste sprint, mas necessário a médio prazo).

### Riscos

- **Risco**: Campos ficam nulos e nenhum badge aparece até o admin configurar.
  **Mitigação**: O componente exibe badges apenas quando o campo está preenchido — ausência é silenciosa, não um erro visual.

## Notas de Implementação

Adições ao `schema.prisma`:
```prisma
model SiteConfig {
  // campos existentes...
  heroBadge1 String?
  heroBadge2 String?
}
```

Props do Hero:
```typescript
interface HeroProps {
  banners: BannerData[]
  heroBadge1?: string | null
  heroBadge2?: string | null
}
```

Renderização condicional:
```tsx
{(heroBadge1 || heroBadge2) && (
  <div className="flex gap-2 justify-center mb-6">
    {heroBadge1 && <HeroBadgePill text={heroBadge1} />}
    {heroBadge2 && <HeroBadgePill text={heroBadge2} />}
  </div>
)}
```
