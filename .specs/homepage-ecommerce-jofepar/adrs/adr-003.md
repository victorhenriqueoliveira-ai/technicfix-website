# ADR-003: layout.tsx Async para Prover Dados ao Header

## Status

Aceito

## Data

2026-07-15

## Contexto

O novo Header precisa de dados de categorias (com filhos) para renderizar o mega-dropdown. O layout.tsx atual é um Server Component síncrono que instancia `<Header />` sem props. Duas estratégias foram consideradas.

## Decisão

`app/(public)/layout.tsx` se torna `async` e executa `getCategoriesWithChildren()` (query Prisma: `db.category.findMany({ where: { parentId: null }, include: { children: true }, orderBy: { name: 'asc' } })`). O resultado é passado como prop `categories` ao novo Header. O Header permanece Client Component apenas para a interatividade do mega-dropdown e da busca.

## Alternativas Consideradas

### Alternativa: Route Handler GET /api/categories + fetch client-side no Header

- **Descrição**: Header faz `fetch('/api/categories')` em `useEffect` para obter categorias.
- **Prós**: Header totalmente self-contained; não altera layout.tsx.
- **Contras**: Adiciona latência de round-trip client-side; requer uma route handler extra; dados chegam após o primeiro render (flash de conteúdo vazio).
- **Por que rejeitada**: Data fetching no servidor é mais performático e evita flash de conteúdo.

## Consequências

### Positivas

- Categorias chegam pré-renderizadas no HTML — sem flash de loading no nav.
- Sem route handler adicional.
- layout.tsx async é padrão comum em Next.js App Router.

### Negativas

- layout.tsx precisa de await — qualquer erro no fetch bloqueia o layout inteiro. Mitigar com try/catch e fallback `[]`.
- Header deixa de ser totalmente self-contained e precisa de `categories` prop.

### Riscos

- Performance: getCategoriesWithChildren é chamada em toda request. Mitigar com cache do Next.js (`unstable_cache` ou revalidate).

## Notas de Implementação

- `app/(public)/layout.tsx`: `export default async function PublicLayout(...)`.
- Extrair função `getCategoriesWithChildren()` em `lib/data/categories.ts` (reutilizável).
- Novo Header aceita `categories: CategorySummary[]` como prop obrigatória.
